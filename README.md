# 🤖 USDT-UAH P2P Monitoring Bot

Telegram-бот для мониторинга курса USDT-UAH на P2P биржах с автоматическими уведомлениями о выгодных предложениях.

## 🔥 Основные возможности

- 📊 **Мониторинг в реальном времени** курса USDT-UAH на P2P биржах
- 🎯 **Настраиваемые диапазоны** - получайте уведомления только в нужном диапазоне цен
- 🏦 **Поддержка бирж**: ByBit (в базовой версии), с возможностью добавления OKX, Binance, BitGet, BingX, MEXC
- 🔔 **Умные уведомления** с защитой от спама и дублирования
- 🔗 **Прямые ссылки** на объявления для быстрого перехода к покупке
- 📈 **Подробная информация** об объявлениях: лимиты, объемы, рейтинги продавцов

## 🛠 Установка и настройка

### 1. Подготовка

```bash
# Клонируем или скачиваем файлы в папку
cd bot

# Устанавливаем зависимости
pip install -r requirements.txt
```

### 2. Создание Telegram бота

1. Идите к [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду `/newbot`
3. Введите имя бота (например "USDT Monitor Bot")
4. Введите username бота (например "usdt_monitor_bot")
5. Скопируйте полученный токен

### 3. Настройка конфигурации

```bash
# Скопируйте файл примера
copy .env.example .env

# Откройте .env и добавьте ваш токен бота
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```

### 4. Запуск бота

```bash
python main.py
```

Или для фоновой работы:
```bash
# Windows
pythonw main.py

# Linux/Mac (screen или nohup)
nohup python main.py &
```

## 📱 Использование

### Основные команды

- `/start` - Запустить бота и зарегистрироваться
- `/help` - Получить справку по командам
- `/set_range <мин> <макс>` - Установить диапазон курса для уведомлений
- `/test` - Проверить текущие доступные предложения
- `/status` - Посмотреть текущие настройки
- `/settings` - Меню настроек (кнопки)
- `/stats` - Статистика уведомлений

### Примеры использования

```
# Установить диапазон от 35.0 до 41.3 грн за USDT
/set_range 35.0 41.3

# Установить более узкий диапазон
/set_range 39.5 40.5

# Проверить что сейчас доступно в вашем диапазоне
/test
```

## 🔧 Настройки

### Файл .env

```env
# Обязательно - токен бота от BotFather
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here

# Опционально - API ключи ByBit (для лучших лимитов)
BYBIT_API_KEY=your_bybit_api_key_here
BYBIT_API_SECRET=your_bybit_api_secret_here

# Путь к базе данных (по умолчанию bot_database.db)
DATABASE_PATH=bot_database.db

# Интервал проверки цен в секундах (по умолчанию 30)
MONITORING_INTERVAL=30

# Диапазон цен по умолчанию
DEFAULT_MIN_RATE=35.0
DEFAULT_MAX_RATE=41.3
```

## ⚙️ Умные фильтры

Бот включает в себя защиту от спама:

- ⏰ **Кулдаун 5 минут** между похожими уведомлениями
- 🔄 **Фильтрация дублей** - не уведомляет о тех же курсах повторно
- 🎯 **Лимит уведомлений** - максимум 3 уведомления за раз
- 📊 **Сортировка по курсу** - сначала лучшие предложения

## 🚨 Решение проблем

### Бот не запускается
1. Проверьте правильность токена в `.env`
2. Убедитесь что установлены все зависимости: `pip install -r requirements.txt`
3. Проверьте права доступа к папке для создания БД

### Нет уведомлений
1. Используйте `/test` для проверки доступных предложений
2. Проверьте настройки командой `/status`
3. Возможно нет подходящих предложений в вашем диапазоне - попробуйте расширить его

### Слишком много уведомлений
1. Сузьте диапазон цен командой `/set_range`
2. Отключите уведомления кнопкой в `/settings`
3. Настройка кулдауна в коде: измените `notification_cooldown` в `price_monitor.py`

## 🔧 Кастомизация

### Изменение интервала проверки
В файле `.env`:
```env
MONITORING_INTERVAL=60  # проверять каждые 60 секунд
```

### Изменение кулдауна уведомлений
В файле `price_monitor.py`:
```python
self.notification_cooldown = 600  # 10 минут между уведомлениями
```

### Добавление новых бирж
1. Создайте новый клиент API в отдельном файле (по примеру `bybit_client.py`)
2. Добавьте проверку в `price_monitor.py` в метод `check_user_notifications`
3. Добавьте биржу в список `available_exchanges` в `telegram_bot.py`
