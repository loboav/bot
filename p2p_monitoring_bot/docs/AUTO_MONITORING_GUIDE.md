# 🤖 Руководство по автомониторингу P2P предложений

## 📋 Обзор

Автомониторинг - это умная система, которая автоматически проверяет P2P предложения каждые 5 минут и отправляет уведомления пользователям при обнаружении подходящих сделок.

## 🎯 Основные возможности

### ✅ Что делает автомониторинг:
- **Автоматическая проверка** - каждые 5 минут сканирует ByBit P2P
- **Умная фильтрация** - только предложения по вашим критериям (цена + лимиты)
- **Мгновенные уведомления** - отправляет в Telegram при находке
- **Защита от спама** - максимум 12 уведомлений в час
- **Прямые ссылки** - сразу можете покупать

### ❌ Что НЕ делает:
- Не совершает сделки автоматически
- Не хранит ваши платёжные данные
- Не требует доступа к вашему аккаунту на бирже

## 🚀 Как настроить

### Шаг 1: Основные настройки
```
/settings → Настроить диапазон курса
Пример: 42.0 43.0 (будет искать от 42.00 до 43.00 UAH)
```

### Шаг 2: Лимиты сделок  
```
/settings → Настроить лимиты
Пример: 10000 50000 (сделки от 10к до 50к UAH)
```

### Шаг 3: Включить автомониторинг
```
/automonitor → Включить автомониторинг
```

## ⚙️ Настройки системы

### 🕒 Временные интервалы:
- **Проверка предложений**: каждые 5 минут
- **Минимум между уведомлениями**: 3 минуты  
- **Лимит уведомлений**: 12 в час

### 🔧 Можно изменить в `.env`:
```env
AUTO_MONITORING_INTERVAL=300        # 5 минут (в секундах)
AUTO_MONITORING_SAFE_INTERVAL=180   # 3 минуты между уведомлениями  
MAX_NOTIFICATIONS_PER_HOUR=12       # максимум уведомлений в час
```

## 📱 Управление через бота

### Команды для управления:
- `/automonitor` - главное меню автомониторинга
- `/settings` - быстрое включение/выключение
- `/status` - посмотреть текущий статус

### Кнопки в `/automonitor`:
- **✅/❌ Включить/Выключить** - переключатель
- **📊 Статус системы** - техническая информация

## 🛡️ Система безопасности

### 🚫 Защита от спама:
- **Максимум 12 уведомлений в час** - не более того
- **Минимум 3 минуты между сообщениями** - не заваливаем
- **Только изменившиеся предложения** - никаких дублей

### 🔒 Приватность:
- Ваши настройки хранятся локально
- Никакой передачи данных третьим лицам
- Токены и пароли не требуются

## 📊 Мониторинг работы системы

### В `/automonitor` → Статус системы:
- **🟢 Активна / 🔴 Остановлена** - состояние сервиса
- **👥 Активных пользователей** - сколько включили автомониторинг
- **⏰ Последняя проверка** - когда в последний раз сканировали
- **📈 Интервалы** - текущие настройки времени

## 🔧 Устранение проблем

### ❌ Не приходят уведомления:
1. Проверьте что автомониторинг **включен** в `/automonitor`
2. Убедитесь что **диапазон цен** настроен в `/settings`
3. Проверьте **лимиты сделок** - возможно слишком узкие
4. Посмотрите не превышен ли **лимит уведомлений** (12/час)

### ⏰ Слишком много/мало уведомлений:
- **Много**: сузьте диапазон цен или увеличьте лимиты
- **Мало**: расширьте диапазон цен или уменьшите лимиты

### 🐛 Система не работает:
1. Перезапустите бота: `Ctrl+C`, затем `python bot/main.py`
2. Проверьте логи в консоли на ошибки
3. Убедитесь что Chrome браузер установлен

## 📈 Рекомендации по использованию

### 🎯 Оптимальные настройки:
- **Диапазон цен**: не шире 2-3 UAH (например: 41.5-43.0)
- **Лимиты сделок**: от 5000 UAH (меньше = большая комиссия)
- **Время работы**: включайте в активные торговые часы (9:00-22:00)

### 💡 Полезные советы:
- **Мониторьте несколько диапазонов**: создайте разные настройки в разное время
- **Быстрая реакция**: при получении уведомления действуйте быстро
- **Проверяйте вручную**: используйте `/check` для дополнительной проверки

## 🔄 Архитектура системы

```
Автомониторинг
    ↓
Каждые 5 минут
    ↓  
Проверка ByBit P2P
    ↓
Фильтрация по критериям пользователя
    ↓
Проверка лимитов уведомлений  
    ↓
Отправка в Telegram (если есть новые предложения)
```

### Компоненты:
- **AutoMonitor** - основной класс управления
- **Rate Limiter** - контроль частоты уведомлений  
- **User Manager** - управление настройками пользователей
- **ByBit Integration** - получение данных с биржи
