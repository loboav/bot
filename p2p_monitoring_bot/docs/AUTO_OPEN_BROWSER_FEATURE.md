# 🌐 Автооткрытие браузера - Новая фича!

## 📖 Описание

Новая функция **автоматического открытия браузера** позволяет мгновенно получать доступ к выгодным P2P предложениям без лишних кликов!

## ✨ Как это работает

1. **Автомониторинг находит выгодное предложение** (каждые 20 секунд)
2. **Бот отправляет вам уведомление в Telegram**
3. **🚀 Ссылка автоматически открывается в вашем браузере**
4. **Вы сразу попадаете на страницу покупки!**

## 🎯 Преимущества

- ⚡ **Мгновенный доступ** - никаких задержек
- 🖱️ **Без лишних кликов** - не нужно открывать Telegram и нажимать на ссылку
- 🏃 **Максимальная скорость** - успевайте первыми на лучшие предложения
- 🎨 **Удобство** - браузер открывается прямо перед вами

## ⚙️ Как включить/выключить

### Через команду `/automonitor`:
1. Отправьте команду `/automonitor` боту
2. Нажмите кнопку **"🌐 Автооткрытие браузера"**
3. Статус изменится на ✅ ВКЛ или ❌ ВЫКЛ

### Через настройки (для продвинутых):
В файле `.env` измените параметр:
```bash
AUTO_OPEN_BROWSER=true   # включено
AUTO_OPEN_BROWSER=false  # выключено
```

## 🔧 Технические детали

- **Кросс-платформенность**: Работает на Windows, Linux, macOS
- **Используется стандартный браузер**: Открывается ваш браузер по умолчанию
- **Безопасность**: Открываются только проверенные ссылки с бирж
- **Множественные ссылки**: Если найдено несколько предложений, все откроются с задержкой 0.3 сек

## 📊 Статистика и логирование

Все действия логируются:
- `🌐 Auto-opening N links in browser for user X` - начало открытия
- `✅ Auto-opened N/M links for user X` - результат
- `❌ Error auto-opening browser` - ошибка (не влияет на уведомления)

## ❓ FAQ

**Q: Можно ли выбрать, какой браузер открывать?**  
A: Открывается браузер по умолчанию в вашей системе. Измените его в настройках ОС.

**Q: Что если браузер не открылся?**  
A: Уведомление все равно придет в Telegram со ссылками. Проверьте логи бота.

**Q: Будет ли открываться много вкладок?**  
A: Максимум столько, сколько предложений в уведомлении (обычно 1-3).

**Q: Можно ли отключить для конкретных бирж?**  
A: Нет, но вы можете отключить биржи в `/exchanges`, и их предложения не будут открываться.

**Q: Работает ли на мобильном?**  
A: Если бот запущен на компьютере, то да. Если на сервере - браузер откроется на сервере (не рекомендуется).

## 🔐 Безопасность

- ✅ Открываются только ссылки с проверенных бирж (ByBit, Bitget, Binance)
- ✅ Никакие внешние ссылки не открываются
- ✅ Функция полностью контролируется пользователем
- ✅ Можно отключить в любой момент

## 🚀 Рекомендации

1. **Используйте на личном компьютере** - так вы сразу увидите открытые вкладки
2. **Настройте узкий диапазон** - меньше ложных срабатываний
3. **Держите браузер открытым** - новые вкладки откроются быстрее
4. **Используйте быстрый интернет** - для мгновенной загрузки страниц
