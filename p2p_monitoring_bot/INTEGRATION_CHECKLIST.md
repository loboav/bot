## 🚀 ГОТОВ К ИСПОЛЬЗОВАНИЮ!

### **Команды для запуска:**

1. **Запустить бота:**
   ```bash
   python bot/main.py
   ```

2. **Проверить предложения:**
   - Отправьте боту `/check`
   - Получите предложения с ByBit и Bitget
   - Нажимайте на прямые ссылки!

3. **Настроить биржи:**
   - Используйте `/exchanges` 
   - Включите/выключите нужные биржи
   - ByBit обычно дает лучшие цены

### **Что ожидать:**
- **ByBit**: ~42.64-42.85 UAH 🏆 (лучшие цены)
- **Bitget**: ~43.38-43.52 UAH 📊 (стабильные курсы)
- **Объединенные данные**: до 20 предложений одновременно!
