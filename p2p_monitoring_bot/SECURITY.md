## 📋 ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ

### 1. Первый запуск
```bash
# Установите зависимости
pip install -r requirements.txt

# Или просто запустите
./start_bot.bat
```

### 2. Настройка токена
Файл `.env` уже создан с вашим токеном. Если нужен новый токен:

1. Получите новый токен у @BotFather
2. Отредактируйте файл `.env`:
   ```
   BOT_TOKEN=новый_токен_здесь
   ```

### 3. Дополнительные настройки в `.env`
```bash
# Браузер
BROWSER_HEADLESS=true          # true = скрытый, false = видимый
BROWSER_TIMEOUT=20             # таймаут в секундах

# Мониторинг  
MONITORING_INTERVAL=60         # интервал проверки
MAX_OFFERS_PER_NOTIFICATION=3  # макс. предложений в уведомлении

# Логирование
LOG_LEVEL=INFO                 # DEBUG, INFO, WARNING, ERROR
```

## 🚨 ВАЖНЫЕ ПРАВИЛА БЕЗОПАСНОСТИ

### ❌ НИКОГДА НЕ ДЕЛАЙТЕ:
- Не коммитьте файл `.env` в Git
- Не делитесь токеном бота с посторонними
- Не публикуйте токен в открытых репозиториях
- Не отправляйте токен в мессенджерах

### ✅ ВСЕГДА ДЕЛАЙТЕ:
- Используйте переменные окружения для секретов
- Регулярно меняйте токены
- Проверяйте `.gitignore` перед коммитом
- Используйте разные токены для dev/prod

## 🔄 СМЕНА ТОКЕНА

Если токен скомпрометирован:

1. Зайдите к @BotFather в Telegram
2. Найдите ваш бот
3. Нажмите "Revoke Token"
4. Создайте новый токен
5. Обновите файл `.env`
6. Перезапустите бота
