# Тестирование автомониторинга

## 🧪 Как протестировать

### 1. Запустите бота:
```bash
python bot/main.py
```

### 2. В Telegram отправьте команды:

#### Шаг 1: Настройте узкий диапазон для автомониторинга
```
/settings
```
- Нажмите "⚡ Диапазон для автомониторинга"
- Введите узкий диапазон, например: `40.5 41.5`

#### Шаг 2: Настройте лимиты для автомониторинга
```
/settings
```
- Нажмите "🔥 Лимиты для автомониторинга"
- Введите лимиты, например: `10000 50000`

#### Шаг 3: Включите автомониторинг
```
/automonitor
```
- Нажмите "✅ Включить автомониторинг"

### 3. Ожидайте уведомлений

Бот будет проверять предложения каждые 20 секунд и отправлять уведомления, если найдет подходящие предложения.

## ✅ Что должно работать:

1. **Нет ошибок** `NameError: AUTO_MONITORING_SAFE_INTERVAL`
2. **Уведомления приходят** без задержек и лимитов
3. **Форматирование** красивое с HTML и эмодзи
4. **Прямые ссылки** на предложения работают
5. **Топ-5 предложений** проверяются быстро

## 🐛 Если что-то не работает:

### Проверьте логи:
- Ищите строки с `🔍 Checking auto monitoring`
- Ищите строки с `📤 Sent notification to user`
- Ищите ошибки `ERROR`

### Типичные проблемы:
1. **Нет уведомлений** - проверьте, что диапазон цен правильный
2. **Ошибки парсинга** - биржи могут изменить структуру страниц
3. **Браузер не запускается** - проверьте установку Chrome/ChromeDriver

## 📊 Мониторинг работы:

### Команды для проверки:
```
/status - показать текущие настройки
/automonitor - показать статус автомониторинга
```
