# 🤖 P2P USDT-UAH Monitoring Bot

Telegram бот для мониторинга курсов P2P торговли USDT-UAH на различных биржах с автоматическими уведомлениями о выгодных предложениях.

## 🎯 Функции

- ✅ **Реальные данные** с ByBit и Bitget P2P в режиме реального времени
- 📊 **Мониторинг курсов** с настраиваемыми диапазонами
- 🤖 **Автоматический мониторинг** каждые 5 минут
- 🔔 **Автоматические уведомления** о выгодных предложениях
- 🔗 **Прямые ссылки** на P2P предложения для удобства
- ⚙️ **Гибкие настройки** пользователей
- 🏦 **Поддержка нескольких бирж** — выбирайте что мониторить!

## 🚀 Быстрый старт

1. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Настройка (БЕЗОПАСНО):**
   - Получите токен бота у @BotFather в Telegram
   - Файл `.env` уже создан с токеном
   - При необходимости отредактируйте `.env`:
     ```
     BOT_TOKEN=ваш_токен_здесь
     ```

3. **Запуск:**
   ```bash
   # Автоматический запуск с проверками
   ./start_bot.bat
   
   # Или вручную
   python bot/main.py
   ```

## ⚡️ Настройки

**Безопасно** через файл `.env`:

```bash
# Браузер
BROWSER_HEADLESS=true          # true = скрытый, false = видимый
BROWSER_TIMEOUT=20             # таймаут в секундах

# Мониторинг
MONITORING_INTERVAL=60         # интервал проверок
MAX_OFFERS_PER_NOTIFICATION=3  # макс. предложений

# Автомониторинг
AUTO_MONITORING_INTERVAL=5          # каждые 5 секунд (МАКСИМАЛЬНАЯ СКОРОСТЬ!)
AUTO_MONITOR_TOP_OFFERS_LIMIT=5     # проверять только топ-5 предложений
AUTO_OPEN_BROWSER=true              # автоматически открывать ссылки в браузере

# Логирование
LOG_LEVEL=INFO                 # DEBUG, INFO, WARNING, ERROR
```

## 📱 Команды бота

- `/start` - Приветствие и инструкция
- `/check` - Проверить текущие предложения (с всех активных бирж!)
- `/exchanges` - **🎯 Выбрать биржи** (ByBit, Bitget и др.)
- `/settings` - Настройки:
  - 💰 Диапазон курса (35-43 UAH)
  - 💳 Лимиты сделок (5000-100000 UAH)
  - 🤖 Автомониторинг (вкл/выкл)
- `/automonitor` - Полное управление автомониторингом
- `/status` - Показать текущие настройки
- `/help` - Помощь по всем командам

## 🤖 Автомониторинг

Бот может автоматически проверять предложения и отправлять уведомления:

⚙️ **Настройки:**
- Проверка каждые 5 секунд (МАКСИМАЛЬНАЯ СКОРОСТЬ! ⚡)
- Только топ-5 предложений
- Без лимитов на уведомления

🚀 **Как включить:**
1. Настройте диапазон цен в `/settings`
2. Установите лимиты сделок
3. Используйте `/automonitor` для включения

🌐 **НОВИНКА: Автооткрытие браузера!**
- При получении уведомления ссылка автоматически откроется в вашем браузере
- Никаких лишних кликов - сразу на страницу покупки!
- Можно включить/выключить в `/automonitor`

📝 **Пример уведомления:**
```
🚨 Автомониторинг: найдено 2 предложения!

1. 💰 ByBit P2P Offer
   👤 Пользователь: TestUser
   💲 Цена: 42.50 UAH за USDT
   📊 Доступно: 100.0 USDT
   💳 Лимиты: 5000 - 50000 UAH
   🔗 Прямая ссылка: [Купить у TestUser]
```
