# 🤖 P2P USDT-UAH Monitoring Bot

Telegram бот для мониторинга курсов P2P торговли USDT-UAH на различных биржах с автоматическими уведомлениями о выгодных предложениях.

## 🎯 Функции

- ✅ **Реальные данные** с ByBit P2P в режиме реального времени
- 📊 **Мониторинг курсов** с настраиваемыми диапазонами
- 🔔 **Автоматические уведомления** о выгодных предложениях  
- 🔗 **Прямые ссылки** на P2P предложения для удобства
- ⚙️ **Гибкие настройки** пользователей
- 🏦 **Поддержка нескольких бирж** (планируется)

## 🚀 Быстрый старт

1. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Настройка (БЕЗОПАСНО):**
   - Получите токен бота у @BotFather в Telegram
   - Файл `.env` уже создан с токеном
   - При необходимости отредактируйте `.env`:
     ```
     BOT_TOKEN=ваш_токен_здесь
     ```

3. **Запуск:**
   ```bash
   # Автоматический запуск с проверками
   ./start_bot.bat
   
   # Или вручную
   python bot/main.py
   ```

## ⚡️ Настройки

**Безопасно** через файл `.env`:

```bash
# Браузер
BROWSER_HEADLESS=true          # true = скрытый, false = видимый
BROWSER_TIMEOUT=20             # таймаут в секундах

# Мониторинг
MONITORING_INTERVAL=60         # интервал проверок
MAX_OFFERS_PER_NOTIFICATION=3  # макс. предложений

# Логирование
LOG_LEVEL=INFO                 # DEBUG, INFO, WARNING, ERROR
```

## 📱 Команды бота

- `/start` - Приветствие и инструкция
- `/settings` - Настройки диапазона курса
- `/check` - Проверить текущие предложения
- `/status` - Показать текущие настройки
- `/start_monitoring` - Включить мониторинг
- `/stop_monitoring` - Выключить мониторинг
