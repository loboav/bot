# 📦 Инструкция по установке бота

## ⚠️ ВАЖНО: Установка зависимостей

Перед запуском бота **ОБЯЗАТЕЛЬНО** нужно установить все необходимые библиотеки Python!

## 🔧 Пошаговая установка

### Шаг 1: Откройте терминал в папке проекта

В VS Code:
- Нажмите `Ctrl + ~` (тильда) или
- Меню: Terminal → New Terminal

Убедитесь, что вы находитесь в папке `p2p_monitoring_bot`:
```powershell
cd C:\Users\CreedmoorForce\Desktop\BOT\bot\p2p_monitoring_bot
```

### Шаг 2: Установите зависимости

Выполните команду:
```powershell
python -m pip install -r requirements.txt
```

**Альтернатива (если первая не работает):**
```powershell
pip install -r requirements.txt
```

Эта команда установит:
- ✅ `python-telegram-bot` - для работы с Telegram
- ✅ `selenium` - для парсинга бирж
- ✅ `requests` - для HTTP запросов
- ✅ `python-dotenv` - для работы с .env файлом
- ✅ `aiohttp` - для асинхронных запросов

### Шаг 3: Настройте токен бота

1. Получите токен у [@BotFather](https://t.me/BotFather) в Telegram
2. Создайте файл `.env` в папке `p2p_monitoring_bot` (если его нет)
3. Добавьте в него:
```
BOT_TOKEN=ваш_токен_от_BotFather
```

### Шаг 4: Запустите бота

```powershell
python bot/main.py
```

## ❌ Частые ошибки

### ⚠️ Ошибка: `pip не является внутренней командой` / `pip is not recognized`

**Причина:** Python не установлен или не добавлен в PATH.

**Решение 1 - Использовать python -m pip:**
```powershell
python -m pip install -r requirements.txt
```

**Решение 2 - Проверить установку Python:**
```powershell
python --version
```
Если команда не работает - Python не установлен или не в PATH.

**Решение 3 - Переустановить Python:**
1. Скачайте Python с [python.org](https://www.python.org/downloads/)
2. При установке **ОБЯЗАТЕЛЬНО** поставьте галочку ✅ **"Add Python to PATH"**
3. Перезапустите VS Code после установки
4. Попробуйте снова: `pip install -r requirements.txt`

**Решение 4 - Добавить Python в PATH вручную:**
1. Найдите где установлен Python (обычно `C:\Users\ИМЯ\AppData\Local\Programs\Python\Python3XX\`)
2. Добавьте в PATH:
   - `C:\Users\ИМЯ\AppData\Local\Programs\Python\Python3XX\`
   - `C:\Users\ИМЯ\AppData\Local\Programs\Python\Python3XX\Scripts\`
3. Перезапустите терминал

### Ошибка: `ModuleNotFoundError: No module named 'telegram'`
**Решение:** Вы забыли установить зависимости! Выполните:
```powershell
python -m pip install -r requirements.txt
```

### Ошибка: `No module named 'dotenv'`
**Решение:** Установите зависимости:
```powershell
python -m pip install -r requirements.txt
```

### ⚠️ Ошибка: `Microsoft Visual C++ 14.0 or greater is required`

**Причина:** Библиотека `aiohttp` требует компилятор C++ для установки на Python 3.14.

**Решение 1 - Установить совместимые версии (РЕКОМЕНДУЕТСЯ):**
```powershell
python -m pip install --upgrade pip
python -m pip install "python-telegram-bot>=20.0,<22.0" "selenium>=4.15.0" "requests>=2.31.0" "python-dotenv>=1.0.0" "aiohttp>=3.9.1"
```

**Решение 2 - Установить Microsoft C++ Build Tools:**
1. Скачайте [Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
2. Установите с компонентом "Desktop development with C++"
3. Перезапустите терминал
4. Попробуйте снова: `python -m pip install -r requirements.txt`

**Решение 3 - Использовать Python 3.11 или 3.12:**
Python 3.14 слишком новый, многие библиотеки еще не адаптированы.
1. Удалите Python 3.14
2. Установите [Python 3.12](https://www.python.org/downloads/)
3. Установите зависимости заново

### ⚠️ Ошибка: `'Updater' object has no attribute '_Updater__polling_cleanup_cb'`

**Причина:** Конфликт версий `python-telegram-bot` и `aiohttp`.

**Решение - переустановить библиотеки:**
```powershell
python -m pip uninstall python-telegram-bot aiohttp -y
python -m pip install "python-telegram-bot>=20.0,<22.0" "aiohttp>=3.9.1" --force-reinstall
python bot/main.py
```

3. Проверьте, что вы в правильной папке: `pwd` (должна быть `p2p_monitoring_bot`)
4. Попробуйте обновить pip: `python -m pip install --upgrade pip`
