# 🤖 P2P USDT-UAH Monitoring Bot - Инструкция по установке

## 📋 Что это за бот?

Этот бот мониторит курсы USDT-UAH на P2P биржах (сейчас ByBit) и отправляет уведомления, когда находятся выгодные предложения в вашем диапазоне цен.

## ✅ Что уже работает:

- ✅ **ByBit P2P** - реальные данные с сайта
- 🔄 **Другие биржи** - планируются (OKX, Binance, MEXC)

## 🔧 Установка и настройка

### 1. Создание Telegram бота

1. Найдите **@BotFather** в Telegram
2. Отправьте команду `/newbot`
3. Придумайте название для бота (например: `My P2P Monitor`)
4. Придумайте username (например: `my_p2p_monitor_bot`)
5. Скопируйте токен (выглядит как: `123456789:ABCdefGHijklMNopQRstuvWXyz`)

### 2. Настройка кода

Откройте файл `bot_config.py` и замените:
```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"
```
На ваш токен:
```python
BOT_TOKEN = "123456789:ABCdefGHijklMNopQRstuvWXyz"
```

### 3. Установка зависимостей

Убедитесь, что установлены все необходимые библиотеки:

```bash
pip install python-telegram-bot selenium
```

### 4. Установка Chrome WebDriver

Бот использует Chrome для получения данных. Нужен ChromeDriver:

1. **Автоматическая установка:**
   ```bash
   pip install webdriver-manager
   ```

2. **Или ручная установка:**
   - Скачайте ChromeDriver с https://chromedriver.chromium.org/
   - Поместите `chromedriver.exe` в папку с ботом

## 📱 Команды бота

### Основные команды:
- `/start` - Приветствие и инструкция
- `/settings` - Настройка диапазона курса и бирж
- `/check` - Проверить текущие предложения
- `/status` - Показать текущие настройки

### Мониторинг:
- `/start_monitoring` - Включить автоматический мониторинг
- `/stop_monitoring` - Выключить мониторинг

## ⚙️ Настройка параметров

В файле `bot_config.py` можно настроить:

```python
# Интервал проверок (в секундах)
MONITORING_INTERVAL = 60  # Проверять каждую минуту

# Скрывать браузер или показывать
BROWSER_HEADLESS = True  # True = скрытый, False = видимый

# Максимум предложений в уведомлении
MAX_OFFERS_PER_NOTIFICATION = 3

# Диапазон курса по умолчанию
DEFAULT_USER_SETTINGS = {
    'min_rate': 35.0,   # Минимальный курс
    'max_rate': 43.0,   # Максимальный курс
    'notifications_enabled': True,
    'active_exchanges': ['bybit']
}
```

## 🎯 Как использовать

1. **Запустите бота** и отправьте `/start`
2. **Настройте диапазон** через `/settings` (например, 41.0 - 42.5 UAH)
3. **Запустите мониторинг** командой `/start_monitoring`
4. **Получайте уведомления** когда появляются выгодные предложения!

## 🐛 Устранение проблем

### Бот не запускается:
- Проверьте, что токен правильно указан в `bot_config.py`
- Убедитесь, что установлены все библиотеки
- Проверьте, что Chrome установлен

### Не получает данные с ByBit:
- Интернет соединение должно быть стабильным
- В файле настроек поставьте `BROWSER_HEADLESS = False` чтобы видеть браузер
- Увеличьте `BROWSER_TIMEOUT` если страницы медленно загружаются

### Ошибки с WebDriver:
- Убедитесь, что установлен ChromeDriver
- Попробуйте обновить Chrome до последней версии
